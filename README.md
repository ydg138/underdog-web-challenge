# 🚀 언더독 레볼루션 신입부원 5일 웹 기초 챌린지

## 👨‍💻 만든 사람
- 이름: 양동규
- 소속: 고려대학교 세종캠퍼스
- 한 줄 소개: 멈추지 않고 계속해서 성장하고 싶은 예비 개발자 양동규입니다.

## 💡 지원 동기
개발의 기초부터 탄탄히 다지고, 함께 도전하며 성장할 수 있는 동아리 부원들과 열정을 나누고 싶어 지원했습니다.

## 🎯 배우고 싶은 것
- 체계적인 팀 프로젝트를 통한 실무 협업 프로세스 체화
- 안전한 웹 서비스 구축을 위한 시큐어 코딩 및 보안 기초

## 📌 프로젝트 소개
HTML과 CSS를 활용하여 직접 제작한 나만의 반응형 자기소개 페이지입니다.

## 🛠 사용 기술
- HTML5, CSS3 (Flexbox, Media Query)
- Git & GitHub

## 🎨 주요 기능 및 페이지 구성
- **Header:** 이름과 한 줄 소개
- **Main:** 프로필 이미지, 자기소개, 관심 분야 3가지, 배우고 싶은 점
- **Footer:** GitHub 바로가기 링크 및 제작자 정보

## 🌐 배포 링크
- [나의 자기소개 페이지 바로가기](https://ydg138.github.io/underdog-web-challenge/)

## 💡 작업하며 배운 점
- HTML 시맨틱 태그를 활용해 웹 페이지의 구조를 설계했습니다.
- CSS Flexbox와 미디어 쿼리를 통해 PC와 모바일 환경 모두 대응하는 반응형 화면을 만들었습니다.
- Git과 GitHub를 통한 버전 관리 및 커밋 프로세스를 체화했습니다.
